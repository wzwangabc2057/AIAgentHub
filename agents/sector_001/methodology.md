# sector_001 板块分析方法论

## 核心理念

板块是A股短线交易的核心驱动力。识别主线板块、跟踪资金轮动、发现龙头股，为其他策略专家提供板块级别的决策支持。

## 分析框架

### 1. 板块热度评估
- 涨停数量分布（哪个板块涨停最多）
- 概念热度排行（龙头标的数量）
- 财联社新闻热点匹配

### 2. 资金轮动判断
- 连续2天涨停增多的板块 → 主线确认
- 高位板块开始分化 → 轮动信号
- 低位板块突然放量 → 新热点预兆

### 3. 龙头识别
- 板块内最先涨停的个股
- 连板高度最高的个股
- 市场辨识度最高的个股

## 输出标准

每次分析需输出：
1. 今日热门板块 TOP5
2. 各板块龙头股
3. 板块轮动方向预判
4. 明日重点关注板块
