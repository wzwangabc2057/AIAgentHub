# 断板反包交易方法论

## 核心理念

断板反包的本质是：**资金涌入的接力**。

> **一句话：断板反包的前提是资金涌入，持有的前提是资金还在。红肥绿瘦就拿着，绿肥红瘦才要跑。**

### 逻辑链条
```
断板 → 资金介入 → 红肥绿瘦 → 反包启动 → 持续涌入 → 持有享受红利
```

### 关键认知
1. **资金是核心**：有资金涌入才有反包，资金撤退就结束
2. 不同连板数的股票，反包打法不同
3. 断板不代表行情结束，可能是中继调整
4. 题材持续性是反包成功的关键
5. 严格止损是生存之道

### 持有标准（核心！）
```
✅ 资金还在进（红肥绿瘦）→ 继续持有，享受红利
❌ 资金开始撤（绿肥红瘦）→ 考虑离场
```

### 操作心态
```
以前：遇到调整就紧张，想跑，频繁换股
现在：只看量能，红肥绿瘦就拿着，跟着资金走
```

## 分级打法（核心！）

### 🔹 首板断板打法

**条件：**
- 连板数 = 1
- 断板后 1-3 天

**入场标准：**
- ✅ 重新站上涨停价时买入
- ✅ 需要放量突破（量比 ≥ 1.5）
- ✅ 分时走势强势（不能拖泥带水）

**规则设置：**
```json
{
  "conditions": {
    "board_count": 1,
    "price_above_limit": true,  // 站上涨停价
    "volume_ratio": {">=": 1.5}
  },
  "action": "EXECUTE_BUY"
}
```

**仓位：** 1R（5%）- 首板风险相对较大

- ✅ 突破要有量能配合
- ✅ 板块有联动效应更佳

## 红肥绿瘦买入模型 ⭐ 核心

> **口诀：红肥绿瘦是好票，绿肥红瘦快跑掉**

### 模型定义

| 形态 | 特征 | 含义 | 操作 |
|------|------|------|------|
| ✅ 红肥绿瘦 | 上涨放量 + 下跌缩量 | 资金在进，惜售心态 | 可买入/持有 |
| ❌ 红瘦绿肥 | 下跌放量 + 上涨缩量 | 资金在跑，拉升无力 | 不要碰 |

### 选股应用

```
1. 打开日K线，看量能柱
2. 对比红柱（上涨量）和绿柱（下跌量）
3. 红肥绿瘦 → 列入候选
4. 红瘦绿肥 → 直接放弃
```

### 持股应用

```
1. 红柱持续 > 绿柱 → 继续持有
2. 绿柱开始放大 → 警惕出货
3. 绿柱持续放大 → 考虑减仓
```

### 急跌时应用

```
1. 急跌但绿柱不长 → 洗盘，可持有
2. 急跌且绿柱放大 → 出货，要跑
```

### 实战案例（2026-01-30）

| 股票 | 量能特征 | 结果 |
|------|----------|------|
| 天奇股份 | 红肥绿瘦 | 涨停+10% ✅ |
| 康强电子 | 红肥绿瘦 | +2.81% ✅ |
| 钧达股份 | 绿柱不长 | 洗盘后收平（被洗出去了）|

## 选股标准

### 必要条件
- [ ] 断板后 ≤ 3天（龙头可放宽到5天）
- [ ] 有明确题材逻辑（不是纯情绪）
- [ ] 断板原因非重大利空
- [ ] **符合红肥绿瘦模型**（新增）

### 加分项
- [ ] 板块龙头/辨识度高
- [ ] 题材有持续性（政策支持/事件驱动）
- [ ] 机构资金关注（北向/龙虎榜）
- [ ] 调整幅度 5%-15%（充分换手）
- [ ] 研报评分 ≥ 70

### 一票否决
- ❌ 重大利空（业绩暴雷/减持/监管）
- ❌ 高位炸板率 > 60%（市场环境差）
- ❌ 纯情绪炒作无实质题材
- ❌ 流动性极差（日成交 < 5000万）
- ❌ **红瘦绿肥（出货形态）**（新增）

## 换手率正确解读 ⭐

> **换手高不一定是坏事，要结合涨跌看**

| 情况 | 含义 | 操作 |
|------|------|------|
| 换手高 + 大跌 | 出货信号 | ❌ 要跑 |
| 换手高 + 没大跌 | 良性换手（有人走有人进）| ✅ 可拿 |
| 换手高 + 上涨 | 资金抢筹 | ✅ 看好 |

**核心：有人卖的同时有没有人买？价格稳住就没事**

## 板块联动与对标股参考 ⭐

> **不只看个股，要看板块和对标股**

### 核心原则

```
板块共振向上 → 龙头继续持有
板块开始分化 → 警惕龙头见顶
对标股强势 → 坚定持有
对标股走弱 → 考虑减仓
```

### 对标股设置

| 持仓股 | 对标股（同板块前排）| 参考逻辑 |
|--------|---------------------|----------|
| 天奇股份 | 铁流股份 | 机器人板块 |
| 康强电子 | 华天科技 | 存储芯片封装 |
| 白银有色 | 湖南黄金 | 黄金有色板块 |

### 实战案例（2026-01-30）

- 天奇股份盘中波动
- 但铁流股份同板块强势
- 决策：不卖，继续持有
- 结果：天奇涨停+10%

### 操作建议

```
1. 持仓股的对标股 → 放入观察股列表
2. 盘中监控对标股表现
3. 对标股强 → 继续拿
4. 对标股弱 → 考虑减
```

## 板块梯队效应 ⭐（龙头战法高手心法）

> **核心逻辑：个股是点，板块是面。没有板块支撑的个股是孤魂野鬼，有板块支撑的个股才是真龙。**

### 梯队确认龙头（Kkmai心法）

```
3板定性：龙头3连板时，板块至少有1只首板助攻
4板定性：龙头4连板时，板块必须有2只跟风股
```

| 情况 | 判断 | 操作 |
|------|------|------|
| 龙头涨+小弟助攻 | 真龙头 | 可重仓 |
| 龙头涨+无人跟风 | 独立妖股 | 降仓位 |

### 情绪周期判断（瑞鹤仙心法）

```
板块高潮日（集体涨停）→ 明天防分歧，是卖点
板块分歧后回流 → 大胆上车，是买点
```

### 赚钱效应判断（炒股养家心法）

```
昨日涨停今日赚钱 → 板块健康，继续持有
昨日涨停今日闷杀 → 板块退潮，果断离场
```

### 盘前必看三确认

```
1. 确认主线：这是有持续性的大题材吗？
2. 确认梯队：龙头涨停时，有小弟助攻吗？
3. 确认节奏：今天是板块高潮日还是分歧回流？
```

## 持股四问检查清单 ⭐

卖出前必问四个问题：

```
□ 趋势是否改变？（5日线是否拐头）
□ 量能是否异常？（是否放量下跌）
□ 逻辑是否改变？（基本面有没有变）
□ 对标股表现如何？（板块是否共振）

四个都没问题 → 拿着，不要动！
```

**实战教训（2026-01-30）：**
- 钧达股份早盘-9%就跑了
- 实际：趋势没变、没放量、逻辑没变
- 结果：被洗盘洗出去了，收盘回到平盘

## 急跌时操作流程 ⭐

> **急跌先看量，缩量不要慌！**

```
1. 先看量能（对比前几日）
2. 换手率是否异常高（>20%警惕）
3. 等30分钟看能否企稳
4. 缩量企稳 → 洗盘，不跑
5. 放量继续跌 → 出货，跑
```

**错误做法：** 只看跌幅就跑
**正确做法：** 看量能再决定

## 出场规则

### 止损（必须执行！）
- **硬止损**：-5% 无条件止损
- **时间止损**：持仓 3 天无起色，减仓

### 止盈
- **第一目标**：+8% 减半仓
- **第二目标**：+15% 清仓
- **移动止盈**：利润回撤 3% 止盈

### 特殊情况
- 反包失败再次断板 → 立即清仓
- 大盘系统性风险 → 减仓观望
- 题材逻辑破坏 → 不等止损直接走

## 风控纪律

### 日内风控
- 日亏损达 -2% → 停止开仓
- 连续 2 笔止损 → 当日暂停

### 仓位风控
- 单只 ≤ 20% 总资产
- 同板块 ≤ 2 只
- 总仓位 ≤ 60%

### 市场风控
- 高位炸板率 > 60% → 降低仓位或观望
- 3板+晋级率 < 20% → 观望为主

## 盘前利空=机会思维 ⭐

> **趋势中的回调是机会，不是风险**

### 思维转变

```
❌ 错误思维：
外盘利空 → 板块要跌 → 规避

✅ 正确思维：
外盘利空 + 长期趋势向上
→ 短期低开
→ 低吸机会！
```

### 判断标准

| 情况 | 操作 |
|------|------|
| 大趋势向上 + 短期利空 | 低开是低吸机会 |
| 大趋势见顶 + 短期利空 | 加速下跌，规避 |

### 实战教训（2026-01-30）

- 盘前看到黄金外盘跳水0.9%
- 错误判断为"黄金见顶风险"，规避黄金
- 中国黄金低开-7%后V型反转涨停
- **漏掉了最好的低吸机会！**

**教训：盘前看到利空，先问"这是不是低吸机会？"**

## 条件单覆盖原则 ⭐

> **没有条件单 = 靠人工盯盘 = 容易漏**

### 两类条件单

```
A类（确定性高）：计划买入的标的
- 中农联合 低开企稳

B类（需触发条件）：可能出现机会的标的
- 中国黄金 低开-5%+反弹
- 白银有色 低开-8%+缩量企稳
```

### 条件单模板

```bash
# 低吸条件单
条件：低开-5%以上 + 反弹1.5%确认企稳
动作：买入

# 回踩条件单
条件：回踩支撑位 + 缩量
动作：买入
```

**原则：不只是"想买的"要设条件单，"可能有机会的"也要设！**

## 每日工作流程

### 盘前（8:30-9:15）
1. 查看晋级率数据，判断市场环境
2. 扫描断板标的池
3. 分析研报，筛选目标
4. **按连板数分类，设置对应规则**
5. **【新增】反向思考：利空是否是机会？**
6. **【新增】调整标的池（根据盘前新信息）**
7. 设置条件单（**包括"可能的机会"**）

### 集合竞价（9:15-9:25）
1. 观察目标股竞价表现
2. 低开 > 5% 的继续观察
3. 平开或高开的评估追涨价值
4. 调整规则启用状态

### 盘中（9:30-15:00）
1. 监控目标股走势
2. **首板：关注是否站上涨停价**
3. **2板+：关注是否突破前高**
4. **龙头：关注是否极致缩量**
5. 持仓股监控止盈止损
6. 记录分析和决策

### 盘后（15:00-16:00）
1. 复盘当日操作
2. 更新方法论
3. 准备次日计划

## 持股纪律：少动多看 ⭐

> **每换一次股 = 多一次掉坑的机会**

### 换股的真实成本

1. 卖飞成本（卖早了少赚的）
2. 追高成本（买贵了多亏的）
3. 手续费成本
4. 心态成本（患得患失）

### 什么时候该换股

```
1. 趋势确认走坏（跌破5日线+放量）
2. 逻辑改变（利空出现）
3. 有更好的确定性机会
```

### 什么时候不该换股

```
1. 看到别的股票涨想换 → ❌
2. 手里的调整一下就慌 → ❌
3. 趋势没变、量能正常、逻辑没变 → 拿着！
```

**一句话：趋势不变不要卖，急跌缩量是洗盘，换股成本最高昂**
